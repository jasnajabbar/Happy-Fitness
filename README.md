Fitness Tracking System 🏋️‍♀️
A full-stack fitness tracking web application that enables users to monitor health, track weight progress, get personalized workouts, and book trainer appointments.

✨ Features
User authentication with unique username 🔐  
Daily weight tracking with progress visualization 📊  
Goal-based workout recommendations (Weight Gain / Loss / Management) 🏋️  
Health-condition submission ❤️
Trainer appointment booking with approval system 📅  
Responsive and user-friendly UI 💻  

🚀 Tech Stack
React.js | Node.js | Express.js | MongoDB | Bootstrap | Axios  

📌 Key Highlights
Built RESTful APIs for smooth frontend-backend communication  
Designed scalable backend architecture using Express & MongoDB  
Implemented dynamic UI rendering based on user goals and conditions  
Used localStorage for efficient session handling
